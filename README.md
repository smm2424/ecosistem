# Ecosistem TEG

Pagina platformei Ecosistem TEG, servită pe https://ecosistem.teg.ro (GitHub Pages).

Pagina nu conține date și nici parole. Intrarea se face cu parola contului (Admin sau User), verificată pe server de un web app Apps Script („Ecosistem TEG”, contul sebastian@teg.ro), care păstrează parolele doar ca amprentă (hash) și dă sesiuni semnate de 12 ore. Ce vede fiecare cont se decide pe server, la fiecare apel.

Aceeași pagină există și la https://smm2424.github.io/oportunitati/ecosistem/.
